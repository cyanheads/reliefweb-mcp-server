# 0.2.1 — 2026-08-25

## Added

- **`.github/CONTRIBUTING.md` and `.github/CODE_OF_CONDUCT.md`** — community-health files scaffolded from the framework's `init` template.

## Changed

- **Tool inputs are strict** — an argument key a tool does not declare is rejected by name before the handler runs. Field-tested: a normal JSON-RPC result carrying `isError: true`, `content[0].text` reading `Input validation error: Invalid arguments for tool <name>: Unrecognized key: "<key>"`, and no `structuredContent`. Root level only — keys inside the raw `filter` record still pass through.
- **The advertised `outputSchema` declares the error envelope** — success fields become optional and `error` is declared, so a client validating `structuredContent` without checking `isError` stops rejecting error results with `-32602`.
- **Advertised JSON Schema is 2020-12**, not draft-07, and the HTTP endpoint serves protocol revision `2026-07-28` alongside the 2025 revisions.
- **`ctx.log` reaches the client** as `notifications/message`.
- **`MCP_SESSION_MODE=stateless`** is now documented consistently — `.env.example` and the README describe the Dockerfile's existing default.
- **The Dockerfile build stage builds natively via `--platform=$BUILDPLATFORM`** — under QEMU, Bun's JavaScriptCore aborted the cross-arch leg with a spurious `MemoryExhaustion` assertion; only the platform-independent `dist/` output crosses the arch boundary, so the build stage has no reason to run emulated.
- **Both production-stage `bun install` steps add `--omit=peer`** — drops the framework's optional peer tiers (test runner, service SDKs, parsers) from the image; nothing this server imports is lost, since its actual runtime deps live in its own `dependencies`.
- **Security reports go to `security@caseyjhand.com`.**

## Fixed

- **`devcheck`'s security-audit classifier parses Bun 1.4's advisory output** — Bun 1.4 changed the package-header separator (`pkg  range` → `pkg@range`) and the dependency-path separator (`›` → `>`); either spelling now parses, so an advisory no longer goes unclassified and fails the gate regardless of severity.
