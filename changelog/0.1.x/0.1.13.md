# 0.1.13 — 2026-07-13

## Changed

- **`list_sources.type` and `search_training.format`** tightened to `z.enum` over the real ReliefWeb taxonomy (`search_training.format` is now `on-site` / `online`); an invalid value is rejected with the valid options surfaced instead of silently returning an empty result set. ([#11](https://github.com/cyanheads/reliefweb-mcp-server/issues/11))
- **Supply-chain hardening** — `bunfig.toml` enables install-time Socket scanning and a 3-day minimum-release-age guard (framework releases excepted); the `Dockerfile` pins the `oven/bun:1.3.14` base, installs with `--ignore-scripts`, and adds a BuildKit cache mount; added `.github/SECURITY.md` and `.gitattributes`.

## Fixed

- **`search_reports` / `search_disasters` country filter** matched only `primary_country.iso3`, dropping records tagged with a non-primary country (regional and cross-border responses); both now filter on `country.iso3`, in line with `search_jobs` / `search_training`. ([#8](https://github.com/cyanheads/reliefweb-mcp-server/issues/8))
- **`list_sources` text search** ignored `shortname`, so acronym lookups like `WFP` or `OCHA` returned nothing; the query now searches `name` and `shortname`. ([#10](https://github.com/cyanheads/reliefweb-mcp-server/issues/10))
- **`list_countries` crisis filter** depended on `current`, an undocumented legacy alias; it now sends `status: ['ongoing']` directly. ([#11](https://github.com/cyanheads/reliefweb-mcp-server/issues/11))
- **Filter-value documentation** — source types, training formats, and country status (`ongoing` / `normal`) — corrected across tool descriptions, `README.md`, and `docs/design.md`. ([#11](https://github.com/cyanheads/reliefweb-mcp-server/issues/11))
